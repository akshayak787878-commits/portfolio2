# Personal Portfolio Website

## Included
- `index.html` — portfolio content
- `style.css` — responsive modern design
- `script.js` — mobile menu and dynamic year

## Before publishing
Replace:
- `Akshay Ak` with your preferred display name if needed
- `your.email@example.com` with your email
- GitHub, LinkedIn, LeetCode and Kaggle placeholder URLs with your real profiles
- Project GitHub link with your actual repository

## Run locally
Open `index.html` in a browser.

## Publish
This static website can be deployed on GitHub Pages, Netlify, Vercel, or another static hosting service.
